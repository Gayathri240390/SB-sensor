# 2. Technical Requirements Document (PRD)

##Overview <br>
This document outlines the tools, technologies and infrastructure used to build the website. It ensures everyone is aligned on the technical stack and key requirements.

##Technical Goals <br>
Build a secure, scalable, and maintainable website using modern, widely-supported tools. Ensure good performance, easy maintenance, and room for future growth.

## Technology Stack
| Area | Tool/Technology | Purpose |
|-------|-------|-------|
| Frontend | React | Builds the user interface with reusable components. |
| Backend | Node.js | Handles server-side logic, APIs, and business logic. |
| Database | PostreSQL | Stores application data such as users, content, etc. |
| Hosting| Vercel | Hosts the frontend with global CDN and automatic deployments |
| Domain & DNS | Cloudfare | Manages domain, DNS, and provides security and CDN. |
| Form Handling | Resend | Handles form submissions and sends email notifications. |
| Analytics | Google analytics | Tracks website traffic and user behavior. |
| Version Control | Git | Stores code, manages versions, and enables collaboration. |
